🌸 FLOWER SHOP PROJECT SUMMARY & CONTRIBUTIONS

PROJECT OVERVIEW:
----------------
A complete e-commerce solution for a flower shop built with Flutter. 
The project follows a modular Clean Architecture and enterprise-grade 
state management.

WHAT WAS IMPLEMENTED:
--------------------
1. CORE FEATURES:
   - Full Authentication system (Login, OTP, Session management).
   - Category-based product browsing and Discovery (Best Sellers).
   - Advanced Shopping Cart with real-time updates.
   - Profile management with editable personal details and addresses.
   - Comprehensive Order History tracking.

2. TECHNICAL INTEGRATIONS:
   - STATE MANAGEMENT: Implemented BLoC/Cubit pattern throughout the app.
   - NETWORKING: Built a robust API layer using Dio and Retrofit with automated code generation.
   - PAYMENTS: Integrated Stripe for credit card processing, including handling browser redirections and success simulations.
   - PUSH NOTIFICATIONS: Integrated Firebase Cloud Messaging (FCM) for real-time delivery updates.
   - LOCALIZATION: Implemented multiple language support (English and Arabic) with RTL layout handling.
   - LOCATION: Integrated Google Maps for precise delivery address selection.

3. ARCHITECTURE & ENGINEERING:
   - CLEAN ARCHITECTURE: Implemented a structured, multi-layered CA (Presentation, Domain, Data) across all features to ensure separation of concerns and high testability.
   - API MODULE: Developed a centralized, type-safe networking layer using Retrofit, Dio, and code generation, including standardized error handling and response wrappers.
   - DEPENDENCY INJECTION: Automated service location and wiring using GetIt and Injectable to maintain a decoupled and modular codebase.
   - TEST SUITE: Wrote and maintained 390+ unit and widget tests covering all architecture layers (Models, Use Cases, Repos, and Cubits).
   - GIT MANAGEMENT: Handled complex merges and resolved critical conflicts in auto-generated/ephemeral directories.
   - CI/CD PREP: Implemented pre-commit and pre-push hooks (formatting, analysis, testing) to maintain code quality standards.

TECH STACK HIGHLIGHTS:
---------------------
- State: flutter_bloc
- Network: dio / retrofit
- DI: get_it / injectable
- Navigation: go_router
- Backend: Firebase (Messaging, Crashlytics, Core)
- Storage: shared_preferences
